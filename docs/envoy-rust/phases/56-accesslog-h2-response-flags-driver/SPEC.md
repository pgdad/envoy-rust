## §1 — Why this pick

The candidate menu (`STATE.md`) weighed: the `DC` downstream-disconnect flag (M45-2 slice, timing-dependent — rejected six consecutive times, ADR-0102 through ADR-0112); the H2 access-log differential driver (M45-1 + M53-2's "(H1)" qualifier) — historically deferred as "materially heavier"; another not-yet-witnessed H1 operator (`%REQUEST_HEADERS_BYTES%`/CF-39-1 — twice-rejected as fragile, ADR-0101/ADR-0112; `%UPSTREAM_CLUSTER%` already witnessed phase 43); a family pivot to xDS CDS/LDS hot-reload (deferred since ADR-0065/ADR-0067 as a heavier live-mutation than RDS/EDS) or LB `least_request`/`random` (needs a new contract-relaxation ADR for non-determinism); and gRPC ALS/OTLP/tracing/tap (heavier sink/transport infra). M45-1 is the cheapest-strong-differential leaf THIS session, for reasons no prior session had:

- **The H1-side cheap vein is now genuinely exhausted.** All six H1 `%RESPONSE_FLAGS%` values (`NR`/`UH`/`UO`/`URX`/`UF`/`UC`) are witnessed (phases 48-53); the request-budget `UO` re-trigger closed at phase 55 (M50-C); `%REQUEST_HEADERS_BYTES%`/CF-39-1 are twice-rejected as fragile; `%UPSTREAM_CLUSTER%` is already witnessed. Every prior deferral of M45-1 (ADR-0102 through ADR-0112, i.e. phases 45 through 55) was a genuine "cheaper alternative exists" call — this session found none remain.
- **State-0 recon narrowed the gap far below its "materially heavier" reputation.** `crates/envoy-http2/src/hcm.rs`'s own doc comment states the H2 HCM "dispatches per-stream through `envoy_http1::hcm::build_response`, identical to the H1 HCM" — H2 reuses H1's routing/synth logic wholesale. The recon (above) empirically confirms `rc`/`rcd`/`proto`/`method` are ALREADY byte-identical between envoy-rust and live Envoy on H2 for this trigger; only the hard-coded `response_flags: "-"` literal at `hcm.rs:948` diverges. The harness driver itself reuses `drive_http2` (already used by `Driver::Http2`/`Driver::Http2ProbeList`) and — pending PLAN-VERIFY — the existing `AccessLogPaths`/`AccessLogByteExactProbe` structs, which carry no H1-specific fields.
- **It is a genuine family unlock, not a narrow re-slice.** Building the H2 access-log driver this phase makes every subsequent H2 `%RESPONSE_FLAGS%`/`%RESPONSE_CODE_DETAILS%` witness a one-flag-at-a-time fixture-only phase — the SAME cadence phases 49-54 established for H1 after phase 48 built the H1 pattern. This mirrors how phase 26 (RDS hot-reload) built the watcher+atomic-swap primitive phase 27 (EDS hot-reload) then reused, and how phase 28 (`RING_HASH`) built xxHash64-from-scratch phase 29 (`MAGLEV`) then reused.
- **The `DC` flag remains genuinely harder.** Six consecutive rejections (ADR-0102 through ADR-0112) for the same reason each time: a timing-dependent mid-request downstream disconnect is hard to drive deterministically. Nothing in this session's recon changes that assessment; `DC` stays deferred.
