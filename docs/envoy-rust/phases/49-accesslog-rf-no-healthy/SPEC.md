## §1 — Why this pick

`%RESPONSE_FLAGS%` already renders in all three encoders (`default_format.rs:60`, `json_format.rs:242`, `command_operator.rs:526`) and phase 48 (ADR-0105) made the field per-request via the derive at `hcm.rs:1232` (consumed at the unified H1 record-build site `:1225`), witnessing the FIRST real flag `NR` byte-exact (fixture `0056`). `UH` is the cheapest next flag:

- **Deterministic + brace-free + 1:1 with an already-set detail.** envoy-rust SETS `response_code_details_for_log = Some("no_healthy_upstream")` at EXACTLY ONE site — `hcm.rs:1000-1001`, the `pick()->None` no-healthy synth-503 arm (phase 45, ADR-0102; the ONLY `endpoint: None` `AttemptResult`). So `Some("no_healthy_upstream")` is 1:1 with the no-healthy-upstream 503 path, exactly as `route_not_found` is 1:1 with the no-route 404 path. The derive extension is therefore provably 1:1 with `UH`, by the same argument that made phase 48's `NR` provably correct.
- **Reuses the already-proven trigger.** The no-healthy-upstream 503 path that phase 45 built fixture `0053-accesslog-rcd-no-healthy` for (a `subset_cluster` with `lb_subset_config` NO_FALLBACK + a route `metadata_match` selecting a non-existent subset → `pick()->None` → synth-503 at routing time). `0053` already proves that 503 path is byte-exact cross-proxy, and its `expectations.yaml` already NAMES "response-flag UH". No new trigger surface.
- **State-0 recon-CONFIRMED at `envoyproxy/envoy:v1.33.0`** (this session — live container, digest `sha256:56da5afd…`): a `GET /` driven at the `0053` topology with `rf:"%RESPONSE_FLAGS%"` added to the `json_format` emits exactly:
  `{"method":"GET","proto":"HTTP/1.1","rc":503,"rcd":"no_healthy_upstream","rf":"UH"}`
  A single clean flag, no combination, deterministic.

envoy-rust on this path TODAY emits `rf:"-"` (the phase-48 derive only maps `route_not_found`; `Some("no_healthy_upstream") != Some("route_not_found")` → `"-"`), so this phase closes a real divergence. This is the cheapest available pick that lights up a new `%RESPONSE_FLAGS%` value, recon-confirmed, with zero new trigger plumbing.
