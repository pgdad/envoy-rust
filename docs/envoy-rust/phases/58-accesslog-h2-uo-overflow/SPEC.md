## §1 — Why this pick

The candidate menu (`STATE.md`, left by the phase-57 close-out) weighed: **M56-1**'s remaining H2 `%RESPONSE_FLAGS%` values (`UO`/`URX`/`UF`/`UC`, now with `UH` also consumed by phase 57); **M57-1** (a trivial cosmetic `content-length` header fix, not a pick driver alone — and this phase does not touch `synth_h2_no_healthy_upstream()`, so it stays deferred); the `DC` flag (rejected seven consecutive times, ADR-0102 through ADR-0114, still timing-dependent); M53-2's BEHAVIOR_CONTRACT "(H1)" qualifier (a trivial doc-only fix, not worth a whole phase on its own); and heavier family pivots (gRPC ALS/OTLP/tracing, CDS/LDS hot-reload, non-deterministic LB policies). `UO` is the cheapest-strong-differential leaf this session:

- **It is the DIRECT sequel to phase 57's `UH` witness**, exactly mirroring the H1 cadence phases 49→50→51→52→53 (`UO` is H1's THIRD flag, phase 50) applied to the H2 cadence 56→57→58 (`NR`→`UH`→`UO`). The trigger config (H2-upstream cluster + `circuit_breakers.thresholds.max_pending_requests: 0`) directly reuses the H1 phase-50 shape, only substituting the downstream listener's `codec_type` and adding the H2-upstream `typed_extension_protocol_options` needed to route through the H2 pool.
- **State-0 recon found the gap is a clean two-site rcd/rf fix, NOT a status-code bug.** Unlike H1 at phase 50 and H2 at phase 57 (both of which needed a genuine status-code correction alongside the rcd/rf gap), this phase's trigger already returns byte-exact 503 on envoy-rust — the H2 pool-overflow machinery (`synth_h2_overflow()`, `PoolError::PendingOverflow`) was built earlier (phase 15's H2 mirror) and is already correct. This is the LOWEST-risk H2 flag witness in the M56-1 sequence so far.
- **It reuses the EXACT H1 discriminator pattern verbatim.** The `attempt.outcome.is_none()` ⟺ overflow discriminator (within the `endpoint: Some` branch) is already landed, battle-tested H1 code (`crates/envoy-http1/src/hcm.rs:1045`-`1052`); this phase transcribes the identical shape onto the H2 caller loop.
- **The `DC` flag remains genuinely harder** (timing-dependent, seven consecutive rejections) — nothing this session changes that assessment.
