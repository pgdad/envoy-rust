- Deviation from PLAN: PLAN's test bodies referenced helpers (`test_pki::gen_pki`, `certified_key_from`, `peer_cert_from_handshake`, `try_handshake`, `cert_contains_san`) that do not exist in 03.1's tests.rs (the actual helper module is named `mod pki`, with a single-leaf `Pki::build()`); PLAN line 1032 explicitly invites adaptation. Adaptations: (1) Extended `pki::build()` to also generate leaf-B (SAN `b.example.com`, distinct keypair, same CA) — added `leaf_b_cert_pem` + `leaf_b_key_pem` fields to the `Pki` struct (additive, no break to 03.1 tests). (2) Added `pki::certified_key_from_pem(cert_path, key_path) -> CertifiedKey` mirroring `lib.rs`'s crate-private `load_certified_key` to avoid widening crate visibility for a test-only consumer. (5) Tests use the established `#[tokio::test(flavor = "multi_thread")]` async style with inlined bind/spawn/connect (matching 03.1's `single_cert_resolver_returns_same_cert_regardless_of_sni`) rather than introducing a generic `peer_cert_from_handshake` helper — each test body is short enough that inlining is clearer.
