## §1 — Why this pick

The candidate menu (`STATE.md`) weighed: the `DC` downstream-disconnect flag (M45-2, timing-dependent — deferred, see §4); the M53-2/M45-1 H2 access-log-driver harness-building phase (heavier scope — building a new differential driver, not a fixture); other Observability operators (`%UPSTREAM_CLUSTER%` already witnessed phase 43; `%REQUEST_HEADERS_BYTES%`/CF-39-1 flagged fragile/weak in ADR-0101's rejected-alternatives list); and **M50-C**. M50-C is the cheapest-strong-differential leaf:

- **Zero source change (recon-confirmed).** Phase 50 already tagged BOTH overflow set-sites with the identical rcd string (`hcm.rs:951`-`:952` for request-budget, `:508`/`:515` for the pool arms) and both feed the SAME derive arm (`hcm.rs:1385`, `Some("upstream_reset_before_response_started{overflow}") => "UO"`). This phase is a pure fixture-only differential witness — the rarest and cheapest possible unit of progress in this project.
- **Zero new harness code, zero new cluster-shape risk.** Fixture `0025` (phase 17) ALREADY proves, cross-proxy, that a `STRICT_DNS` cluster with `{{BACKEND_HOST}}` + `circuit_breakers.thresholds.max_requests: 0` produces the overflow disposition on both proxies — this phase reuses that EXACT proven shape (not a new/unprecedented combination), adding only a `json_format` access-log block.
- **Closes a named, explicitly-deferred carry-forward.** M50-C has been open since phase 50 (`BEHAVIOR_CONTRACT.md:1020`: "The request-budget (`max_requests`) overflow UO is in-process-backstopped only — differential witness deferred (M50-C)") and re-listed as still-live in every STATE.md candidate menu through phase 54.
- **State-0 recon reconfirmed a known mechanism from a new angle, and caught a topology trap early.** The naive assumption (mirror fixture `0058`'s no-backend-spawn topology) FAILS, for the exact reason ADR-0047 already documents (the `upstream_cx_total` prefetch divergence) — recon caught this BEFORE the fixture was authored by re-deriving it independently, then confirmed the corrected design (fixture `0025`'s reachable-backend shape) is byte-exact on both live Envoy and the current envoy-rust tree.
