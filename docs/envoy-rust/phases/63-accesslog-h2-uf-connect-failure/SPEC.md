## §1 — Why this pick

The candidate menu (`STATE.md`, left by the phase-61 close-out) weighed: **M56-1**'s remaining H2 `%RESPONSE_FLAGS%` values (`UF`/`UC`, now with `UH`/`UO`/`URX` also consumed by phases 57/58/61); **M57-1** (a trivial cosmetic `content-length` header fix, not a pick driver alone — this phase does not touch `synth_h2_no_healthy_upstream()`); the `DC` flag (rejected at every prior consideration, ADR-0102 through ADR-0118, still timing-dependent); M53-2's BEHAVIOR_CONTRACT "(H1)" qualifier (a trivial doc-only fix); the phase-58 carry-forward candidate (the H2 request-budget arm's own differential fixture — smaller than a full phase, better folded into a future phase that touches that arm for an unrelated reason); and heavier family pivots (gRPC ALS/OTLP/tracing, CDS/LDS hot-reload, non-deterministic LB policies). Sibling phase directories `59`/`60`/`61-perf`/`62` (H1-perf-work, disjoint surface, disk-committed by OTHER sessions with their own draft SPECs/ADRs) are NOT this thread's concern. `UF` is the cheapest-strong-differential leaf this session:

- **It is the DIRECT sequel to phase 61's `URX` witness**, exactly mirroring the H1 cadence phases 49→50→51→52 (`UF` is H1's FIFTH flag, phase 52) applied to the H2 cadence 56→57→58→61 (`NR`→`UH`→`UO`→`URX`, now `UF`).
- **State-0 recon confirms the wire shape is IDENTICAL to the already-landed H1 witness** — same status (503), same flag (`UF`), same non-deterministic-rcd disposition (OMIT from the fixture, exactly as fixture `0060` already established) — so this phase reuses a FULLY validated pattern with zero open empirical questions.
- **The fix is a genuine, previously-unvalidated correctness bug** (502 instead of 503) — the SAME class of differential gap phases 50/57/52 each fixed for their own H2/H1 arms, so this phase both improves differential fidelity AND closes an M56-1 slice in one move.
- **The topology needs NO backend spawn** (a literal dead endpoint, mirroring fixtures `0057`/`0058`/`0060`/`0066`'s NO-backend-spawned discipline) — the cheapest possible topology in this sub-family, with NO new harness allowlist wiring required (unlike phase 61's `URX`, which needed a health-aware-backend + per-path-map allowlist edit for its `/retry-exhausted` route).
- **The `DC` flag remains genuinely harder** (timing-dependent, nine consecutive rejections through ADR-0118) — nothing this session changes that assessment.
