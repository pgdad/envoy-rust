### Task 9 review fix — strip outgoing transfer-encoding + tighten host invariant

- Commit: d8b2360
- Important fix I1: replaced `find_header(&req.headers, headers::HOST).unwrap_or("")` in the BuildOutcome::Proxy arm with `.expect("build_response rejected missing/empty Host before BuildOutcome::Proxy")`.
