### Phase-74 §5 state-0/1 brainstorm (active phase)

- **Pick:** the access-log FILTER subsystem **arm #6, `metadata_filter`** — the SIXTH `AccessLogFilter` oneof arm, gating a sink on DYNAMIC METADATA. `SPEC.md` at `docs/envoy-rust/phases/74-accesslog-metadata-filter/SPEC.md`; ADR-0154 fired.
- **Why this cleared the cheapest-strong bar:** the "needs dynamic-metadata plumbing" premise that deferred this arm three times is now FALSE — `AccessLogRecord` already carries the store and it is in scope at BOTH emit gates; the phase-35/36 `MetadataMatcher`/`ValueMatcher`/`StringMatcher` types are the SAME upstream message and are reused verbatim; `ValueMatcher::matches` is `pub` + store-agnostic; the `set_metadata`/`header_to_metadata` producers are fixture-proven (`0041`-`0044`); the differential driver needs ZERO change.
- **The one genuinely new mechanical cost:** `LogFilter::should_log` must be widened to carry the metadata store — MEASURED **102** call sites (4 production, ~98 in-process tests). This is the whole reason §8 (~935 LoC) exceeds phases 70-73 (~630-670); it carries no design risk. PV-5 weighs the 4th-parameter widening (recommended) against a record-based consolidation.
- **MEASURED live (all six probes port-mapped, graceful-stop flush, `envoyproxy/envoy:v1.33.0`):** `matcher` is OPTIONAL upstream (`metadata_filter: {}` VALIDATES — a load-parity trap); `match_if_key_not_found` is a BoolValue WRAPPER whose DEFAULT is `true` (measured by the absent → explicit-`false` polarity flip, which `--mode validate` provably cannot reach); the rule is `None => match_if_key_not_found`, `Some(v) => value.matches(v)`; a missing NAMESPACE ≡ a missing KEY.
- **NEW divergence trap — CF-74-1:** `matcher.invert` is ACCEPTED but **INERT** on the access-log path (reproduced twice; an `invertBOGUS` control is REJECTED, proving the field is genuine). SCOPED OUT — "implementing" it would CREATE a divergence. It stays boot-fatal here per the ADR-0049 posture.
- **Rejected on MEASURED cost, not assumption:** a `HeaderMatcher`-parity phase (CF-72-1/CF-72-2) — the one-expression fix at `matcher.rs:51` is read by FIVE call sites across FOUR subsystems (H1+H2 route matching, RBAC, fault, JWT authn, access-log filtering), ZERO fixtures exercise `invert_match` (so it needs new route-path AND access-log-path fixtures), and phase 72's own mutation check already proved a naive uniform fix breaks the `present_match` parity pin. **It remains the strongest NEXT candidate.** Also rejected: `duration_filter` (cheap wire shape, but a timing-flaky predicate), `grpc_status_filter` (no gRPC data plane → vacuous differential; note the enum spelling is `CANCELED`, one L), `runtime_filter` (no RTDS), the fixture-only Minors (M73-R2/M71-3/M71-6 — no new observable), and every §9 family opener.
- **Split gate:** §8 ~935 net LoC / ~12-15 tasks → UNDER the ~1500 LoC / ~25 task gate; single phase. ADR-0156 held in reserve as a formality.
