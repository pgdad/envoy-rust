### Phase-28 state-1 brainstorm (pick + scope; the Load-balancing-family-opener rationale)

> Authored at the phase-28 state-1 brainstorm (`superpowers:brainstorming`). Records WHY phase 28 is the `RING_HASH` LB opener + the alternatives weighed; the full reasoning is **ADR-0069**. (Relocates to `STATE_HISTORY.md` per ADR-0035 / §4.1 inv. 9 at the phase-28 state-6 close-out, when row `28` flips `done`.)

- **The pick OPENS a new family (Load balancing), departing the six-phase xDS arc.** The project shipped only `ROUND_ROBIN` (phase 02); the LB family (`§9`: least_request/random/ring_hash/maglev/subset/locality-weighted/priority) is foundational — subset/locality/priority LB all layer onto a real policy-dispatch + a request-hash plumbing this phase builds. It was the phase-25 brainstorm's "larger/riskier — needs a NEW distinguishable-backend harness" deferral, which **phase 27 just retired** by building the two-backend harness seed.
- **`RING_HASH` is the only DIFFERENTIABLE LB opener.** Byte-exact selection equivalence is provable only for a DETERMINISTIC policy (consistent-hashing maps a request hash key → a fixed host); `random`/`least_request` (P2C-random) are non-deterministic → cannot be byte-exact-differentiated without a contract-relaxation ADR (defer). `ring_hash` (ketama ring) over `maglev` (heavier prime-permutation table) is the gentler opener. **And the differential is LOCALLY observable** (a normal request/response — no file-watch/reload trigger), retiring the Linux-CI-only-iteration tax that phases 26/27 paid (memories `host-docker-desktop-virtiofs-no-inotify` + `envoy-rust-state4-ci-first-execution`).
- **Rejected (ADR-0069):** **CDS/LDS hot-reload** — the named next xDS layers, but CDS needs a swappable `ClusterManager` (`{ clusters: HashMap<String, Arc<Cluster>> }` built-once-immutable today, `cluster.rs:745`) + per-cluster pool/HC/OD/budget lifecycle churn on add/remove + identity-preservation across the swap → heavy, split-prone, AND its reload-differential is CI-only (the EDS-over-CDS least-invasive reasoning, ADR-0067). Deferred-not-dropped — the phase-26/27 watcher+swap+warm-reject primitive waits for them. **maglev** (heavier); **random/least_request** (non-deterministic); **the gRPC/ADS transport** (still ADR-0014/H2-trailers-blocked); **the network-filters opener** (low leverage).
- **MVP scope (ADR-0069 / SPEC §2):** `LbPolicy::RingHash` + `RingHashLbConfig` (min/max ring size; XX_HASH only) + a route header `hash_policy` on `RouteAction_Route` + **xxHash64 (seed 0) written from scratch** (D-3.2; no hash crate exists/permitted) + the ring build + next-clockwise lookup + the request-hash key threaded through `pick_endpoint()` (public) / `pick()` (private) — the round-robin path a no-op (all 35 existing fixtures stay green) + fixture 0036 (one RING_HASH cluster, two distinguishable backends, a hash-key sweep asserting same-key→same-backend bilaterally) + a backstop + a BEHAVIOR_CONTRACT "LB selection" extension. **Deferred non-goals:** maglev; least_request/random; MURMUR_HASH_2; cookie/source-IP/query/filter-state hash sources + terminal/multi-policy/regex_rewrite; weighted-ring replicas; `use_hostname_for_hashing`; RING_HASH+EDS-hot-reload re-ring; subset/locality/priority LB; CDS/LDS hot-reload.
- **The core differential risk** (envoy-rust must replicate Envoy's EXACT ring [hash fn / ring-key string format / replica math] + header-hash to select the SAME backend) is de-risked by the **state-2 §6.2 LOCAL reconnaissance** (sweep keys against `envoyproxy/envoy:v1.33.0`, record key→backend mappings, reverse-engineer the ring), with a documented **same-key-stability fallback** equivalence (per-proxy consistency + distribution sanity, defined by ADR-0070) if exact cross-proxy identity proves intractable. **ADR-0070 reserved** for the §6.2 reconciliation, **ADR-0071 reserved** for the §6.1 split (PLAUSIBLE — 28.1 config-foundation / 28.2 ring+fixture). SPEC spec-reviewed → APPROVED-WITH-MINORS (0C/0I/4 doc Minor; M1 [public `pick_endpoint` / private `pick`] + M2 [H1→503/H2→502 no-host asymmetry] folded).
